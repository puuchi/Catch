# 待办页第一轮操作约定

日期为 2026 年 11 月 16 日。本轮交付可交互样板，用于确定待办页的布局和操作。下表中的“样板采用”是本轮候选方案，正式接入时以用户体验后的反馈定稿。

| 操作 | 样板采用的结果 | 体验时怎么判断 |
| --- | --- | --- |
| 点新增输入框 | 展开备注、紧急、日期、重复和创建/取消 | 主输入框容易找到，展开后没有多余大边框 |
| 标题 Enter | 新增或保存，输入法选字期间继续输入 | Enter 不触发另一枚按钮，也不误提交选字 |
| 备注 Enter / Ctrl+Enter | Enter 换行，Ctrl+Enter 创建或保存 | 多行备注可写，保存快捷键有明确提示 |
| 点取消 / 编辑时 Esc | 关闭编辑，放弃本次未保存修改 | 不会误保存草稿或触发播放 |
| 查看待办 | 备注正文直接显示，日期/重复/资料另行排列 | 读内容时不需要点“备注” |
| 单击待办标题 | 展开或收起备注和日期/重复/资料 | 收起后保留标题与主操作，再点标题展开 |
| 双击待办标题 | 打开编辑弹窗 | 两次点击能进入编辑，收起动作不干扰双击 |
| 查看长备注 | 默认最多两行，点展开可读全文 | 默认紧凑，展开后内容完整 |
| 点播放 | 优先继续同一待办未结束的事项 | 暂停后再次点播放，保留事项和累计，投入次数增加 |
| 同一待办正在计时时再点播放 | 回到同一个投入摘要 | 不增加新事项，不增加投入次数 |
| 右键 / 点 ⋯ / Shift+F10 | 打开同一个编辑、重复、删除菜单 | 常驻按钮减少，仍有可发现的菜单入口 |
| 点编辑 | 打开标题、备注、紧急、日期图标的编辑弹窗 | 日期由日历图标选择，悬停提示截止日期 |
| 点资料数量 | 展开资料列表 | 资料与备注分行，资料标题单击可打开 |
| 资料菜单 | 仅显示图标，Tooltip 分别为“修改”和“移除” | 菜单短小，悬停能看懂含义 |
| 完成与历史 | 完成项进入历史，历史按月分组 | 月份清楚，能返回待办 |
| 点归档 | 归档已完成，历史仍能查看 | 归档不会删掉完成历史 |
| 删除待办 | 移到样板回收站，可恢复 | 不会因误删一项而退出当前页面 |
| 设置重复 | 每天、每周、每隔 N 天、每月，设定后显示短说明 | 重复入口紧凑，规则能读懂 |

## 本轮按反馈采用的交互

- 备注默认两行，较长内容可以展开。可以在预览的设计控件中调整行间密度和字号。
- 编辑、删除收进菜单，同时保留可见的 ⋯ 入口。双击标题也能编辑。
- 待办和资料的右键菜单仅显示图标，原操作名称放到 Tooltip，同时保留键盘名称和菜单导航。
- 编辑继续使用弹窗。样板用于判断弹窗是否顺手，反馈后再定稿。
- 标题 Enter 保存，多行备注 Ctrl+Enter 保存，Esc 取消编辑。
- 编辑备注的占位符包含“Enter 换行 · Ctrl+Enter 保存”，底部独立提示删除。紧急与日历图标并列，截止日期写入日历 Tooltip。
- 历史页保留“返回待办”的文字，常用归档与回收站用图标。

## 今日投入与植物成长

- 保留顶部今日投入，单击展开独立的成长面板。
- 当天尚未选定植物时展示五种选择，预览后点击“今天选它”确定。
- 选定后展示同一株植物的五种阶段形态，突出当前阶段，较早阶段有完成标记，未来阶段降低视觉强调。
- 显示达到下一阶段还需投入的分钟数，保留每日目标设置和开关。
- 外观透明度属于外观设置，成长面板展示植物和每日目标。
- 预览采用 24 分钟示例投入，阶段继续采用现有 Rust 规则的 0%、10%、30%、60%、100% 阈值。调整每日目标可试验阶段与目标达成的表现。

## 样板的体验范围

使用示例待办、示例资料和本地交互状态。当前投入摘要用于演示事项复用与暂停/继续。重复表单展示规则选择，真实周期生成由现有 Rust 业务接入阶段处理。示例资料可在样板内查看名称和地址，真实文件选择、系统打开、磁盘保存及跨模块一致性属于正式接入阶段。

## 正式接入时的验收约定

- 复用依据待办 ID，同名待办各自独立。多个历史未结束事项优先运行中的，其次最近更新的暂停事项。
- 保留原事项的 ID、累计、历史进展与资料，沿用后端有效投入计算。
- 完成和删除待办继续沿用各自业务语义，计时与完成的联动另按已评估需求实施。
- 同一操作提交期间阻止重复执行，失败保留输入并显示原因。
- 所有新日期与历史分组使用宿主当地日期。样板中的“今天”固定为本次评审日期，避免示例截图在跨日后失去上下文。
- 周期待办的真实调度、资料打开、归档/回收恢复由现有应用服务处理，接入时核对普通与周期待办。

第一轮评审后记录需要调整的布局和操作，再完成待办页正式接入，随后沿用统一规则推进其他模块。
