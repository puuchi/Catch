## 环境与限制

- 本机隔离安装目录不等于全新 Windows 系统；没有在独立干净 Windows 10/11 虚拟机或另一台机器验证。
- 多显示器边界有单元测试，但没有现场物理插拔第二台显示器；关机/睡眠异常恢复主要由业务测试与模拟系统事件覆盖。
- 当前安装包未签名，未配置自动更新。
- 单文件替换与归档恢复不保证断电下绝对耐久；旧版或外部编辑器不能同时写同一数据目录。
- 活动 UI 拆出了时间选择器、详情、后台列表和共享前台选择规则；主活动控制器仍负责编辑/导航编排，后续功能增长时可以继续细分。
- 界面模块使用 Electron 回归和浏览器检查；不宣称所有 DOM 代码都已静态类型化。网站状态测试不替代完整浏览器自动化回归。
