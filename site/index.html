    想知道的问题。

    网页演示和桌面应用有什么区别？＋

    网页可体验资料关联、重复待办、计时、查看过程和植物成长。文件和文件夹地址仅用于模拟关联。桌面版可打开本机资料、保存实际记录，以及补录和编辑时间轴。

    Catch 免费吗？支持什么系统？＋

    Catch 是免费的个人开源项目。当前提供 Windows 10 / 11 的 x64 版本，安装后即可离线使用，不需要 Node.js。原创代码采用 MIT，字体和绿芽素材遵循各自许可证。

    我的记录存在哪里？＋

    桌面应用的记录保存在本机 %APPDATA%\io.github.puuchi.catch.next。无需注册账号。备份时先正常退出，再复制整个数据目录。

    怎样安装和更新？＋

    在 GitHub Releases 选择 Catch 的 Windows x64 安装包，双击安装后从开始菜单打开。如果系统缺少 WebView2，首次安装需联网。安装包尚未签名，Windows 可能显示发布者未知或信誉提示，可按 Release 中的 SHA-256 校验文件核对。
